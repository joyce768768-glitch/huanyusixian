## 📖 项目简介

**寰宇思贤·小读者** 是一款面向家长与孩子的儿童阅读盲盒电商 H5 应用，融合「绘本盲盒 + 阅读启蒙 + 分销推广 + 会员体系」于一体，致力于通过趣味化的盲盒玩法激发孩子的阅读兴趣，同时为家长提供一站式的童书选购与会员服务体验。

## 🛠️ 技术栈

| Tailwind CSS | 4.x | 样式方案 |
| Material Design 3 | - | 设计规范 |
| Lucide React | 0.546 | 图标库 |

| Google GenAI | 1.x | AI 能力接入 |

## ✨ 核心功能

### 🏠 首页模块
- 邀请好友赚佣金 Banner
- 会员开通引导
- 推荐商品 / 盲盒展示
- 分类标签筛选

### 🛒 商品 & 购物
- 商品详情页（图文介绍、规格选择）
- 购物车管理
- 收藏夹
- 结算抽屉组件

### 👤 用户中心
- 个人资料展示
- 订单管理（待付款 / 待发货 / 已完成）
- 钱包与交易明细
- 收货地址管理
- 会员中心
- 优惠券中心

### 🤝 分销推广
- 分销伙伴列表
- 邀请好友分享抽屉
- 伙伴业绩统计

### 🎨 通用组件
- 顶部导航 Header
- 底部 Tab 导航 BottomNav
- 结算抽屉 CheckoutDrawer
- 分享抽屉 ShareDrawer

## 🚀 本地运行

**前置条件：** 已安装 Node.js（建议 18+）

```bash
# 1. 克隆仓库
git clone https://github.com/joyce768768-glitch/huanyusixian.git
cd huanyusixian

# 2. 安装依赖
npm install

# 3. 配置环境变量（如需 AI 功能）
cp .env.example .env.local
# 在 .env.local 中填入 GEMINI_API_KEY

# 4. 启动开发服务器
npm run dev
```

启动后访问：http://localhost:3000
